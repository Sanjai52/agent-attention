# Agent Attention Dogfood Journal

This journal is local and opt-in. Do not record prompts, command output, source
code, or other sensitive payloads.

## Weekly entry

- Week of:
- Alerts received:
- Alerts judged unhelpful:
- Channels disabled because of noise:
- Missed events noticed:
- Quiet-hours or focus surprises:
- Configuration changes:
- Follow-up:

Use `agent-attention stats --since 7 --json` for local delivery counts. The
export never sends telemetry or contacts a network service.
