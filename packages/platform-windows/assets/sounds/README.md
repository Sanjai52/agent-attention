# Bundled default sounds

The five files in this directory are the F4-R4 defaults. A missing `filePath` in
playback resolves to one of these by `soundId`:

| Sound id | File | Envelope |
|---|---|---|
| `attention` | `attention.wav` | 660 Hz → 880 Hz |
| `approval` | `approval.wav` | 523 → 659 → 784 Hz (three notes) |
| `idle` | `idle.wav` | 440 Hz |
| `complete` | `complete.wav` | 523 → 784 Hz |
| `failure` | `failure.wav` | 330 → 220 Hz (descending) |

All are PCM, mono, 22 050 Hz, 16-bit little-endian, with a 6 ms fade in/out to
avoid clicks. Each file is under 20 KB. They were generated by:

```powershell
node packages/platform-windows/scripts/generate-default-sounds.mjs
```

The generator is committed so the assets can be reproduced; runtime code never
writes them.
